Fleet v0.1.0-rc.25 makes the installation-wide software API available through the outbound Converge connector. The relay and the self-hosted manager must both run rc.25 for Converge to show the fleet-wide release picker and request a coordinated update. The standalone console also includes the corrected upgrade guidance.

An installed rc.22 manager should first update manager and ingest to rc.23, then update them directly to rc.25. Agents may remain on rc.22 during these bridge steps. Once manager and ingest run rc.25, choose rc.25 once in Fleet software settings to update the agents in a compatible order. The host updaters verify the signed bundle and pause if a host fails verification. HAProxy keeps serving its loaded configuration during management restarts.

The signed compatibility range permits rc.22 through rc.25 managers and agents to coexist during the qualified transition. Rc.24 installations can also update to rc.25 with the manager update control; rc.24 does not expose the fleet-wide API through the outbound connector.
