Fleet v0.1.0-rc.22 adds signed software update controls to the standalone console. Operators can inspect verified release notes, publisher, compatibility, and artifact hashes before requesting an update. The Software page shows manager, ingest, agent, and HAProxy versions alongside host updater state and update progress across the fleet.

This release adds host-owned updaters for Linux agents and the manager. Agent updates restart the agent while HAProxy continues serving its current configuration. Manager and ingest updates briefly interrupt management and telemetry. The first move from rc.21 requires a manual signed upgrade of the manager and agents, followed by installation of the separate host updaters. The signed managed-upgrade range covers rc.22 peers only; rc.21-to-rc.22 mixed-version operation is not qualified for UI-managed updates.

The release build uses Go 1.26.11, including the November net/http security fix.
