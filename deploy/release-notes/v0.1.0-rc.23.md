Fleet v0.1.0-rc.23 prepares an installed rc.22 manager for the next additive database schema and installation-wide software rollout. It retains the existing management API and database schema, so the rc.22 Software page can request this signed manager update through the existing host updater. The host installer in this release recognizes additive schema 22 while preserving rollback to the retained rc.22 release.

The signed compatibility range permits rc.22 and rc.23 managers and agents to run together during this bridge upgrade. HAProxy keeps serving while manager and ingest restart; management and telemetry briefly pause. Agent software does not need to change for this bridge step.
