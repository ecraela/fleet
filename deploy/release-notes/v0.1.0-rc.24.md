Fleet v0.1.0-rc.24 adds one desired signed release for a self-hosted installation. The manager plans its own update, ingest, and every enrolled agent in a compatible order, records durable progress, and pauses when a host fails verification. The Software page shows a single release picker and per-host progress instead of requiring repeated node updates.

This release adds additive database schema 22. An rc.22 installation must first update its manager and ingest to rc.23, whose host installer accepts schema 22; agents can remain on rc.22 during that bridge step. After the manager reaches rc.24, choose rc.24 once in Fleet software settings to update remaining agents. Manager and ingest restarts briefly interrupt management and telemetry; HAProxy continues serving its current configuration. Host updaters verify the signed release before changing local software.

The signed compatibility range permits rc.22 through rc.24 managers and agents to coexist during the qualified transition. The standalone console also improves cluster loading and uses compact software controls.
