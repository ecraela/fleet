# Console screenshot

`self-hosted-console.jpg` shows the self-hosted console using the local two-node
demo. All measurements in the image come from synthetic demo traffic.

To refresh it, start the [local demo](../../README.md#try-it-from-source), sign in
as `demo-viewer`, open **Local two-node HAProxy demo → Overview**, and wait for
both nodes and their charts to report. Capture the actual page with the account
menu and all setup drawers closed.
