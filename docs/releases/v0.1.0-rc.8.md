# Private release candidate: v0.1.0-rc.8

Applications have a Geography tab in the standalone and Converge consoles.
It shows country/ASN request totals, unknowns, coverage and each node's current
database status. Country and ASN groups link to filtered request search; request
details show the selected address-source class and lookup result.

Lookup is opt-in and runs on the nodes. Install operator-provided Country/ASN
MMDB files, the private `cv3` frontend log profile and an explicit local trust
policy. Production datasets are not bundled or downloaded. Raw client addresses
and forwarding headers never reach the manager, log store or consoles.

Upgrade manager, ingestion and any Converge relay before enabling the new agent
profile. Older `cv1`/`cv2` records remain searchable with unknown geography. Node
identity, keys, configuration history and independent local login are retained;
the database schema and control protocol versions are unchanged.

Direct-peer mode ignores forwarded headers. Forwarded modes require specific
trusted proxy CIDRs; they do not make an unrestricted listener safe. No blocking,
country access policy, WAF enforcement or DNS change is enabled by this release.

Validation includes parser/trust and tenant API tests, both consoles, and the
real two-node HTTP/HTTPS scenario: 1,232 neighboring-app requests without failures,
unknown handling, spoof rejection, database corruption/recovery, retained history
and unchanged application routing, shared TLS, identities and keys. Demo lookups
use pinned synthetic upstream test databases, not production location data.

See the [Geo setup guide](../geography.md) and [ADR 0055](../adr/0055-haproxy-local-geography.md).
