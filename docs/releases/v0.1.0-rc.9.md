# Private release candidate: v0.1.0-rc.9

This candidate hardens relay responses, host installers, encrypted recovery,
login admission, observation history and background incident evaluation.
It also makes unresolved command-result retries idempotent in audit history.

Use `python3 -I` for host tools. Authenticate the release manifest and both
Python files before execution; selfhostctl additionally pins and verifies its
agentctl helper. Keep using the current authenticated host tools when selecting
an older compatible runtime for software rollback. Older host tools are not
compatible with the isolated selfhostctl bootstrap.

Restore verifies and decrypts a private ciphertext snapshot. Allow space for
that bounded copy as well as decrypted recovery staging. Node identities,
private keys, local accounts, configuration history and optional Converge links
remain in persistent state; upgrades never re-enroll nodes.

Automatic discovery retains at most 1,024 configuration versions per node.
Latest observations remain visible after the cap, and authorized edits and
rollouts can still capture their exact rollback base. Both consoles explain
when automatic history is full. Normal one-second reports remain supported;
control admission is bounded across streams and reconnects.

The acceptance scenarios start a withdrawn node without replaying shared
configuration init containers. Geo spoof checks wait for their own complete
request evidence, so late trusted batches cannot change the result.

Upgrade the manager, ingestion and Converge relay before the agents. The
control protocol and database schema are unchanged from rc.8; self-hosted
installations on rc.7 use the existing additive schema upgrade. HAProxy writes
still require permissions and local policy, without approvals. DNS review
is unchanged. The repository and GHCR package remain private.
