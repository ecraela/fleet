# Private release candidate: v0.1.0-rc.7

The self-hosted installer can configure an outbound Converge relay without
editing generated Compose files. The relay destination, optional private CA and
connector identity remain in installation state through upgrades, software
rollback and encrypted restore. Standalone login stays enabled.

This is a historical release note. For current host-tool security requirements,
use the [installation runbook](../self-hosted-installation.md). The command
below describes the original rc.7 interface, not a current install recommendation.

After authenticating the release and host tools, configure an installation with:

```sh
python3 selfhostctl.py connector-configure --directory /srv/haproxy-manager \
  --connector-relay-url https://relay.example.com
```

For a private relay CA, add `--connector-ca-file /path/to/relay-ca.crt`. Only
public certificates are accepted. The command does not pair an account or
grant cloud management access. A local administrator completes pairing using a
short-lived code from Converge. Unlink before changing a paired relay URL.

At release time, rc.7 was the host tool for subsequent lifecycle operations. The database
and storage profile are unchanged from rc.6. Existing node identities and keys
are retained; ingestion receives no connector credentials or cloud login key.
The repository and release distribution remain private.

See the [connector guide](../converge-connector.md) and
[installation runbook](../self-hosted-installation.md). Qualification uses the
published rc.6 baseline and rc.7 candidate on clean Linux before deployment.
