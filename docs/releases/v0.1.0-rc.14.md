# Private release candidate: v0.1.0-rc.14

**Qualified on 3 November 2026.** The repository and release images remain private.
RC.13 remains unqualified; use RC.14's authenticated installer and exact artifacts.

This candidate includes AGPL-3.0-only licensing, optional commercial licensing
and paid support, the local matching-source offer, dependency notices and exact
Alpine runtime source packaging. Third-party components retain their own terms;
see [licensing](../../LICENSING.md) and [distribution packaging](../third-party.md).

RC.13's clean published-asset test exposed an installer regression: a fresh
installation accepted the source archive, but re-upgrading after rollback
rejected its retained copy when it exceeded 1 MiB. RC.14 uses the same bounded
legal-artifact limit when retaining an authenticated release again. Metadata
keeps its smaller bound; changed files, symlinks and nonregular inputs remain
rejected. A regression test covers install, upgrade, rollback and re-upgrade
retention with a signed archive above 1 MiB.

Cold Linux acceptance also reached its previous CI time limits. Job budgets now
allow the complete source collection, application scenarios and cold restore to
finish. Per-operation limits, traffic assertions and recovery guards are
unchanged. A cancelled run is not a successful qualification.

Use this candidate's authenticated host tools when installing or changing a
release. They still accept older signed releases for software rollback. Keep
the current host tools when selecting an older runtime. RC.13's tags and
artifacts have not been rewritten.

The [RC.12 raw rollback binding limitation](v0.1.0-rc.12.md) still applies:
preserve the entire agent state, including `configuration-bindings/`. Never
re-enroll nodes or discard keys/history to work around missing bindings.

Runtime protocol and persistent state schemas are unchanged.
